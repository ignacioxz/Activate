# Activate

App en SwiftUI para iOS, macOS y visionOS.

## Requisitos

- Xcode 27 o superior
- iOS 27 / macOS 27 / visionOS 27

## Cómo empezar

1. Clona el repositorio.
2. Abre `Activate.xcodeproj` en Xcode.
3. Selecciona un destino (simulador o dispositivo) y ejecuta con `⌘R`.

## Estructura

| Ruta | Descripción |
| --- | --- |
| `MyApp/MyApp.swift` | Punto de entrada de la app |
| `MyApp/ContentView.swift` | Vista principal |
| `MyApp/Assets.xcassets` | Recursos (colores, imágenes) |
